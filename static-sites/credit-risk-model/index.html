Production Readiness Assessment

Data Definition

Only application-time features should enter training. Leakage features (InterestRate, BaseInterestRate, MonthlyLoanPayment) inflated test RMSE by ~9%.

Calibration Monitoring

Prediction intervals are slightly overconfident (78% within 1σ vs expected 68%). At extreme risk bands, calibration error reaches 2.3 points. Production deployment requires per-cohort reliability curves.

Fairness Auditing

Significant bias detected: unemployed applicants are under-predicted by 2.3 points (p < 0.001). Fairness remediation (reweighing, bias mitigation) is needed before deployment.

Explainability

SHAP or LIME per-prediction explanations required for audit trail. Current VIP provides global importance but no instance-level interpretability.

Model Card & Compliance

Document intended use, performance boundaries, fairness thresholds, and regulatory compliance per evolving AI/ML in credit scoring standards.

Score: 4/10 vs Production

As a course project: 8/10. As a production risk model: 4/10. The gap is not in algorithm choice but in data definition, leakage control, and model governance infrastructure.

Project Upgrade

What Changed

  • Leakage control: removed InterestRate, BaseInterestRate, MonthlyLoanPayment. Honest CV RMSE reported alongside original.
  • Repeated CV: 5×5 folds inside training set only. Single held-out test evaluation.
  • Calibration: reliability curves, prediction interval coverage, error distribution diagnostics.
  • Stratified error: segmented RMSE and bias by income, credit, bankruptcy, employment, and risk band.
  • Fairness auditing: t-tests for systematic bias per segment.
  • Model governance: production readiness assessment with specific remediation recommendations.
